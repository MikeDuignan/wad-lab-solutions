Week 9, exercise 4: Forms, utilities and your own CSS (answer key)

PARTS 1 AND 2: enquiry.html and styles.css (the finished pages are in this folder)
  The table: form-select goes on the select and form-control on a text box (and on a textarea). The red messages need two things: the browser's own checks (required, type, minlength) decide what is valid, and the script adds the class was-validated to the form; Bootstrap's invalid-feedback and valid-feedback classes only style the messages. d-none hides the picture by default and d-md-block brings it back from 768 pixels up. The first rule, on button, lost to Bootstrap's .btn rule: that rule is a class selector, which is more specific than the element selector button, even though Bootstrap's file loads first. The link to styles.css comes after the Bootstrap link so that, when two rules are equally specific, the later one wins; a stylesheet that loads first loses. The variables for hover and pressed: --bs-btn-hover-bg, --bs-btn-hover-border-color, --bs-btn-active-bg and --bs-btn-active-border-color (and --bs-btn-focus-shadow-rgb for the ring).
  A change made in the Styles panel changes only the copy of the page in that browser tab, so it disappears when the page is loaded again; a fix has to be saved in styles.css. Checking in the browser helps visitors, but they control their browsers and can bypass the page, so the program that receives the form on the server must check the data again.

PART 3: PUZZLES
  Puzzle 1: Left is at the left end of the line and Right is at the right end (justify-content-between puts the spare space between them). align-items-center lines them up by their middles, so the small one sits halfway down the tall one.
  Puzzle 2: At 400 only Box C (no display class) is visible. At 800 Box A (d-none d-md-block) is visible too, because medium starts at 768. Box B (d-none) is hidden at every width.
  Puzzle 3: Step 1 (all empty): Name, Email, Topic and Message are red, with their messages, and the cursor is in Name. Step 2: Name is green (Name entered), Email is red (ann is not an email address), Topic is green, Message is red (Hi is under ten characters), and the cursor moves to Email, the first box that fails. Step 3: all four are green; no box is red and nothing is sent. The email message says only that the format was accepted.
  Puzzle 4: Both buttons stay Bootstrap blue. The rule on button is an element selector and loses to the class rules that give a btn-primary its colour, even though it comes later.
  Puzzle 5: At rest One is blue and Two is green (its --bs-btn-bg and --bs-btn-border-color were replaced). When the pointer is over Two it turns a darker blue, not dark green: the rule only replaced the background and the border colour, so Bootstrap's own hover variables still apply to it. Setting the hover variables as well, as in exercise 4, is what keeps the hover colour green.
  Puzzle 6: Wednesday and Thursday have no bullets. The two items in the inner list (Morning and Afternoon) do have bullets (open circles, the browser's style for a list inside a list): list-unstyled is only on the outer list, and the inner one is a new list that needs the class itself.

PART 4: THE FOUR TICKETS
  1. fix-1-label-for.html: the label says for="e-mail" but the input's id is email. The for attribute must match the id exactly; otherwise the label is not connected to the box, so clicking it does nothing and a screen reader does not announce it with the box. Write for="email".
  2. fix-2-select-class.html: the class form-select is on each option, where it does nothing, and not on the select. Move it to the select element.
  3. fix-3-missing-class.html: the form has no class needs-validation. The script looks for it with document.querySelector('.needs-validation'), gets null, and the next line fails with Uncaught TypeError: Cannot read properties of null (reading 'addEventListener'). Add class="needs-validation" to the form.
  4. fix-4-css-order.html: the link to styles.css comes before the Bootstrap link. Both rules have the same weight (one class each), so the later one wins, and that is Bootstrap's. Move the link to after the Bootstrap link.
