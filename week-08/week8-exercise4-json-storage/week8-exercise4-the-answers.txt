Week 8, exercise 4: JSON and browser storage (answer key)

PART 1: PUZZLES. WHAT EACH PAGE SHOWS
  Puzzle 1: {"name":"Aoife","age":30,"active":true}. Every property name and every string value is in double quotes. The number 30 and the boolean true have none. There are no spaces, and no comma after the last pair.
  Puzzle 2: ["tea","milk",2]. An array becomes square brackets with the values inside, the strings in double quotes and the number without. The single quotes of the JavaScript do not survive: JSON insists on double quotes.
  Puzzle 3: string, 51, 6. setItem turns the number 5 into the text 5, and getItem gives that text back. A plus with a string joins, so the text 5 and the number 1 make 51. Number turns the text back into a number, and then the plus adds.
  Puzzle 4: [object Object]. setItem turns whatever it is given into a string first, and every object becomes those same words. The data is lost, so JSON.stringify is needed before storing an object.
  Puzzle 5: Nothing saved, getItem gave null. getItem gives back null when no value is stored under the key, so the test entry !== null is false and the else branch runs. The plus turns null into the word null.
  Puzzle 6: 45 and 20. parse gives back an object with a number width and a string height, because 5 is in double quotes in the text. A plus with a string joins, so 4 and 5 make the text 45. Times converts the string to a number, so 4 times 5 is 20.
  Puzzle 7: one null three, and then null null. removeItem('b') deleted only the pair with the key b, so getItem('b') gives null. clear deleted every pair that the site had stored, so a and c are gone as well. Pages opened from the disk share one store, so clear also removes what your other pages saved.
  Puzzle 8: Reading the text... and a red error in the Console. JSON insists on double quotes, so the single quotes make the text invalid and JSON.parse stops the script, Expected property name or '}' in JSON at position 1. The last line never runs. Console: Uncaught SyntaxError: Expected property name or '}' in JSON at position 1, reported on line 17.

PART 2: THE FOUR TICKETS
  1. fix-1-no-stringify.html: localStorage.setItem was given the object itself, so the browser stored the text [object Object]. On the next load JSON.parse cannot read that text and stops the script. Store JSON.stringify(entry). The bad value stays in storage until it is deleted (Application tab, Delete Selected) or overwritten by a new save. Before the fix the Console shows Uncaught SyntaxError: is not valid JSON, on line 30.
  2. fix-2-no-parse.html: getItem gives back text. A string has no property called seats or name, so both are undefined, and reading a missing property is not an error. Turn the text back into an object with JSON.parse before using the properties.
  3. fix-3-no-null-check.html: with nothing stored, getItem gives null, JSON.parse(null) gives null, and a for...of over null is not allowed (shoppingList is not iterable). Check for null before parsing and looping: if (savedListText !== null) { ... }. Before the fix the Console shows Uncaught TypeError: shoppingList is not iterable, on line 25.
  4. fix-4-name-mismatch.html: the name is saved under the key visitor-name and read back under visitorName. getItem on a key that has nothing stored gives null, which is not an error, so the if block never runs. The key must match exactly, hyphen and capital letters included.

THE PAGES YOU BUILD
  note-keeper.html: setItem stores the text under the key note. The first table row on the sheet, then each action, gives the messages listed. After Forget note the key is gone and a reload says No note saved yet.. An empty note is stored as an empty string, which is not null, so the page shows Saved note: with nothing after it.
  packing-list.html: with no storage the list is lost on a reload. With setItem and JSON.stringify the Application tab shows the value ["Towel","Sunscreen"], but the page cannot read it back until getItem, the null check and JSON.parse are added. Storing the array without JSON.stringify makes the browser store the text Towel (an array turned into text), and the next reload fails with SyntaxError: Unexpected token 'T', "Towel" is not valid JSON; delete the bad value in the Application tab to carry on. removeItem deletes the one pair. The return in addItem stops an empty box from adding an empty item.
  visit-counter.html: the stored values are strings (3, not 3 the number), so Number turns the stored text back into a number before the plus. Without Number the counts become 1, 11, 111. Local storage is shared by every tab of the site (the new tab continues at 4), and session storage belongs to one tab (the new tab starts at 1 and counts 2 on its reload). Reset removes both pairs.
