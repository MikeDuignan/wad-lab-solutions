  Puzzle 2: Report to follow., and a ReferenceError. total was declared with const inside the function, so it exists only between that function's braces. The line outside it asks for a name that does not exist there. Console: Uncaught ReferenceError: total is not defined, reported on line 21.
  Puzzle 3: Report to follow., and a TypeError. The method is push, with a small p.   Puzzle 4: Report to follow., and a TypeError. Brackets after a name mean run it, and total is the number 10, not a function. A TypeError means a value was used in a way that it cannot be. Console: Uncaught TypeError: total is not a function, reported on line 16.
  Puzzle 5: Nothing happens, and the Console shows a SyntaxError. The closing brace of the function is missing, so the browser reaches the end of the script still waiting for it.   Puzzle 8: Step one is done. then Step two is waiting. and Step three is waiting., and a TypeError. PART 2: THE FOUR TICKETS
  1. fix-1-reference-error.html: a ReferenceError: nexttide is not defined. The constant was created as nextTide, with a capital T, and JavaScript treats capital letters as different letters. The error appears only on the click because the line is inside the function. Compare the name with the line that created it. Before the fix the Console shows Uncaught ReferenceError: nexttide is not defined, on line 19.
  2. fix-2-type-error.html: a TypeError: Math.Floor is not a function. The method is Math.floor, with a small f. Names are looked up exactly, capital letters included, and when the Console says is not a function you check the spelling and the capitals of the name just before the brackets. Before the fix the Console shows Uncaught TypeError: Math.Floor is not a function, on line 15.
  3. fix-3-syntax-error.html: a SyntaxError: Unexpected token '{'. The bracket that opens the condition is never closed, so the browser meets the brace while still inside the brackets. A syntax error is found before anything runs, so the button was never connected. Write if (score > 50). Before the fix the Console shows Uncaught SyntaxError: Unexpected token '{', on line 19.
  4. fix-4-wrong-total.html: no error, a wrong answer. The children's part of the sum uses adults again instead of children: 2 times 12 plus 2 times 7 is 38. console.log('adults', adults, 'children', children) or a breakpoint on the total line shows each value, and the second product is the one that is wrong. Write children * childPrice.

THE PAGES YOU BUILD
  ferry-fare.html: the finished page shows Fare: €26 for 4 passengers. console.log writes Passengers: 4 Fare: 26 to the Console and nothing to the page. Each experiment gives the message and line in the table on the sheet: passengrs gives a ReferenceError only on the click (the line is inside the function); getElementByID gives a TypeError as the page loads and stops the script, so the button is never connected; fare-totals gives Cannot set properties of null on the line that uses null, although the mistake is on the line that made it; the missing brace gives Unexpected end of input on the last line of the script, not where the brace is missing. A breakpoint on the line that works out the fare shows passengers as 4 before the line runs, and fare as 26 after one step over.
  bill-split.html: as typed from the sheet, the page says Each person pays €92.25, which is more than the whole bill, and the Console is empty. console.log shows total 90, tip 9, people 4 and share 92.25. Division is done before addition, so tip / people (2.25) is added to the total. The fix is brackets: (total + tip) / people, which gives 24.75.
