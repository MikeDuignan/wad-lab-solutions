# Web Application Development: lab solutions

This repository holds the solutions to the weekly lab exercises, one folder per
week. Each solution is plain HTML that opens in any browser.

## How to use them

Try the exercise yourself first. Then compare your pages with the solution, and
paste both into the [W3C validator](https://validator.w3.org/nu/) if they behave
differently. Your page does not have to match the solution character for
character. It has to do the same job, and the validator should report no errors
or warnings.

To get the files, click the green **Code** button and choose **Download ZIP**.

## Pictures

The pictures the exercises use are included, in the `images` folder of each
solution that needs them. They were drawn for the course. The starter files,
which have the same pictures, are on the Moodle course.
