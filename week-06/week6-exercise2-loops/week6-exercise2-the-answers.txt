Week 6, exercise 2: Loops (answer key)

PART 1: PUZZLES. WHAT EACH PAGE SHOWS
  Puzzle 1: 123. The loop makes three passes (i is 1, 2, 3) and each writes i straight after the last.
  Puzzle 2: 012. i starts at 0 and the loop stops when i is no longer less than 3, so it writes 0, 1 and 2.
  Puzzle 3: ***. i is 1, 2, 3 (4 is not less than 4), so three stars.
  Puzzle 4: 10. total grows 0 + 1, + 2, + 3, + 4: 10.
  Puzzle 5: 1, 2 and 3, each on a line of its own, because the br tag is written after each number.
  Puzzle 6: 1 2 3 (with a space after each number). The while loop writes count, adds one, and stops when count is 4.
  Puzzle 7: 12. On the pass where i is 3 the if is true and break leaves the loop before the write, so only 1 and 2 are written.
  Puzzle 8: 4. After the loop ends, i still holds the value that made the condition false, 4. The loop body is empty, so the page writes only that.

PART 2: THE FOUR TICKETS
  1. fix-1-lap-counter.html: document.write puts each value straight after the last. Add + "<br>" after the i: document.write("Lap " + i + "<br>");
  2. fix-2-count-to-six.html: the condition i < lastNumber is false when i is 6, so the sixth pass never happens. Change < to <=.
  3. fix-3-keeps-asking.html: the page sets message but never leaves the loop, so it asks a third time even after the right word. Add break; on the line after message = "The gate opens"; inside the if. The final message is the same either way, so only the number of pop-ups shows the mistake: two with the fix (tulip, harbour), three without.
  4. fix-4-stamp-card.html: "i" in quotes is the letter i, as text. Take the quotes away: "Stamp " + i + "<br>".

THE PAGES YOU BUILD
  floors.html, times-table.html and reading-room.html: the test tables are in the sheet. Notes: with <= 5 the loop writes five floors and with < 5 only four. i = i + 2 writes 1, 3, 5 for five floors, and 1, 3, 5 for six as well (7 is too many). The while version writes the same lines, but its update (i++) sits inside the body, where it is easy to forget: with it forgotten the loop would never end.
