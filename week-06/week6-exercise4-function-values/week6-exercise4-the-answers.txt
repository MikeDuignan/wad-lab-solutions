  Puzzle 4: Done. getFive() returns 5, but nothing uses the value, so it is lost.

PART 2: THE FOUR TICKETS
  1. fix-1-lost-value.html: getArea returns 60, but the call does nothing with it. Put the call inside alert: alert(getArea(wallWidth, wallHeight));
  2. fix-2-swapped-values.html: the arguments go to the parameters by position. getChange(paid, cost) was called as getChange(cost, paid), so it worked out 13 - 20. Swap the arguments.
  3. fix-3-text-not-numbers.html: prompt gives text, and the plus sign joins "20" and "4" into 204. Wrap each prompt in Number(...).
  4. fix-4-name-only.html: document.write(getResult) writes the function itself, because getResult with no brackets is only the name. Call it: getResult(examScore).
